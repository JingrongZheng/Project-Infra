# Project Infra · Windows 便携版

解压整个压缩包，在 ProjectInfra 文件夹中双击 ProjectInfra.exe。
无需安装 Python，不需要输入命令，也不需要安装原来的 wheel。
不要只拿走单个 EXE，旁边的 _internal 文件夹是应用的一部分。

第一次使用：选择你的项目文件夹。如果是空项目，会询问是否生成项目骨架；已有文件会保留。
应用会自动选择空闲端口，并在系统默认浏览器打开看板。无需自己配置端口或打开终端。
下一次双击会自动打开最近使用的有效项目；要换项目，使用“选择项目文件夹”。

应用窗口负责启动与停止服务，看板仍在浏览器中显示。
只关闭浏览器不会停止服务；关闭应用窗口会停止本次启动的所有项目服务。
可以通过“停止所选服务”单独停止一个项目。重复打开同一项目会复用本窗口的服务。

## 搬动与迁移

退出应用后，把整个 ProjectInfra 文件夹移到新的位置，仍可双击启动。
项目文件独立保存在你选择的项目目录中，搬应用不会自动搬项目，也不会把项目数据藏进程序。
换电脑时同时复制你要使用的项目目录。若保留应用与项目的相对位置，最近项目仍可识别；
找不到旧项目时重新选择一次即可。只复制应用目录不会带上原电脑上的项目。
最近项目记录保存在应用旁边的 settings.json；请解压到可写位置，不要在压缩包中直接运行。
关闭应用后移除 settings.json 可清空最近记录，不影响项目文件。

## 给 Agent 使用

让 Agent 打开项目目录并先读 AGENTS.md。应用启动项目时会更新 .work/infra-runtime.md，
其中给出当前机器可用的命令行入口，不要求系统安装 Python。
应用中的 project-infra.exe 是给 Agent/终端调用的配套命令，人工日常启动双击 ProjectInfra.exe 即可。
搬应用后重新打开项目，会更新这份临时路径说明。

这是本地便携版本，没有发布到公共平台；不自动安装更新，也不修改系统 PATH。
