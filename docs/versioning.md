# 版本与项目格式

1.0.0 是首个正式版。程序版本遵循 MAJOR.MINOR.PATCH；项目格式独立标记在 `.project/config.toml`，本版为 `schema_version = 2`。

## 1.x 的稳定边界

- 支持由 1.0.0 创建且校验有效的项目：设计主干、Plan / Experiment、长期知识、共享实现索引、资料和历轮审查记录继续可读写。保持既有字段、状态和引用的语义。
- 补丁版用于修复；次版本可增加可选能力，不要求重写已有项目才能继续原有工作。新增可选字段不应使旧内容失效；编辑记录保留未修改的字段和章节。
- 破坏格式或已有行为的变更需要新的主版本，并说明迁移方式；不会把升级变成静默重建项目。当前遇到未知或不合法的 schema_version，拒绝初始化与业务写入。
- `init` 补齐缺失骨架，不覆盖用户已有文档、代码和 Plan；模板更新不会自动改写既有项目执行计划。1.x 若需要迁移，必须另行说明并提供明确操作。

共享实现整理是 Plan 执行计划中的真实检查项：非放弃 Plan 交付或结束前，必须存在且完成，并有结果记录；允许按探索进展调整位置和范围。程序检查记录，具体整理、重跑及结论真实性由执行者负责。

## 哪些属于临时实现

`.work/`、本机能力记录、权限恢复日志、内部 `_review-*` 命令、浏览器内部 HTTP 接口以及布局坐标不是稳定集成协议。不要据此保存长期项目知识或编写外部集成。正式审查适配器协议见 [接入指南](reviewer-integration.md)。

0.x 是探索版本，不追溯承诺兼容。格式标记相同也不表示早期项目已经满足当前校验；保留原文件并按诊断修正，不自动覆盖。

## 运行与审查边界

发行安装包面向 Windows x64，自带 Python 运行环境；需要系统默认浏览器。源码基本工作流可独立运行，Windows 审查写保护要求支持持久 ACL 且当前用户可恢复权限；不支持的文件系统、重解析点和硬链接会拒绝启用审查能力。

写保护防止普通文件操作，项目拥有者仍能主动修改 ACL；不是对恶意本机程序的安全隔离。独立会话由宿主或适配器提供。托管适配器的普通子孙进程由程序停止后才恢复写入；宿主会话必须由宿主停止再回传。程序不证明模型诚实、意见质量或项目方法成立。
