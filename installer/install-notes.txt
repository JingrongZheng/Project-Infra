Project Infra 安装说明

此向导只安装软件，项目位置在首次启动后单独选择。
软件和项目可以位于不同磁盘；无需另外安装 Python 或 Node。

请选择独立、可写的软件安装目录。默认仅为当前用户安装，不修改系统 PATH。
首次启动后，选择已有项目或空文件夹；空文件夹会在确认后生成项目骨架。

卸载会移除软件和快捷方式，不删除你选择的项目目录或探索记录。
最近项目设置可能保留在安装目录，以便重新安装后继续使用。
安装或卸载前请先关闭 Project Infra 应用窗口及其命令行服务。

质疑者接入说明
软件不包含 Agent 或模型。启动项目后由执行者按 AGENTS.md 自检，可接入已有 subagent、独立进程或其他独立会话。未接入时界面会提醒并关闭质疑功能，其他功能可正常使用；不会自动安装额外 Agent。
